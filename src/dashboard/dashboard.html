Privacy · Terms
Automated accessibility checks
Aggregates deterministic browser assertions that verify foundational platform accessibility mechanics across both dedicated accessibility/ guides and UI, CSS, and HTML component guides. Each check is classified into one of five dimensions: Focus & inert management; Motion, contrast & visual; ARIA, roles & live regions; Form labels & grouping; and Keyboard & non-gesture operability. Automated checks catch common AI omissions in code but do not measure full WCAG compliance or replace manual and assistive-technology testing.
Uncached vs. total token accounting
Uncached tokens = total − cached (fresh input + output + thinking tokens). Multi-turn agents re-read cached prompt prefixes on every tool turn (roughly 85–96% cached for Claude Code and Codex CLI, ~20% for Antigravity CLI), so both uncached tokens and totals with cache share are shown.
