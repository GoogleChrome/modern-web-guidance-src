Cross-cutting accessibility subscore
Aggregates the deterministic grader assertions that test accessibility requirements across both dedicated accessibility/ guides and UI, CSS, and HTML component guides. Each check is classified into one of six dimensions: Focus & inert management; Motion, contrast & visual; ARIA, roles & live regions; Form labels & grouping; Keyboard & non-gesture operability; and checks from dedicated accessibility/ guides. Graded-check counts differ between modes when a run fails before grading (counted as one failed check).
Uncached vs. total token accounting
Uncached tokens = total − cached (fresh input + output + thinking tokens). Multi-turn agents re-read cached prompt prefixes on every tool turn (roughly 85–96% cached for Claude Code and Codex CLI, ~20% for Antigravity CLI), so both uncached tokens and totals with cache share are shown.
