Cross-Cutting Accessibility Subscore
Aggregates ~107 accessibility-related grader assertions across ~34 guides (both dedicated accessibility/ guides and UI/CSS/HTML component guides). Classified deterministically into 5 dimensions: Semantics & Landmarks, ARIA Roles & Live Announcements, Keyboard & Focus Management, Visual / Contrast / Reduced Motion, and Automated Axe-Core Audits.
Uncached vs. Total Token Accounting
Uncached Tokens = total - cached (fresh input + output + thinking tokens billed at full price). Multi-turn agents re-read cached prompt prefixes on every tool turn (often 85%–96% cached), so we surface both uncached tokens and total tokens with cache hit share.
