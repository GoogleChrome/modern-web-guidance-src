This is an application command menu. Open File, then use arrow keys within the menu. The navigation links on this page remain ordinary links and use normal Tab navigation.

Keyboard guidance · Testing guidance

Keyboard guidance

Use Enter, Space, or Down Arrow to open the menu. Use Up and Down to move between commands, Right Arrow to open Preferences, Left Arrow or Escape to return, and Tab to leave the menu.

Testing guidance

Test this demo with keyboard-only input, VoiceOver, and NVDA. The visible focus indicator and status message make the result easy to inspect.
