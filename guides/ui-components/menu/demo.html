Project brief

Two independent popup menus. Each trigger is an ordinary button and its own Tab stop: focusing it does nothing, and hovering it while the other menu is open does nothing. The links on this page remain ordinary links and use normal Tab navigation.

Keyboard guidance · Testing guidance

Keyboard guidance

Press Enter, Space, or Down Arrow on a trigger to open its menu and move to the first command. Use Up and Down to move between commands, Right Arrow to open a submenu such as Export, Left Arrow or Escape to return from the submenu, Escape in the top-level menu to close it, and Tab to leave the menu.

Testing guidance

Test this demo with keyboard-only input, VoiceOver, and NVDA. The visible focus indicator and status message make the result easy to inspect.
