Modern CSS Popover Menu

This demo showcases a wrapperless popover menu styled with CSS Subgrid, anchored with CSS Anchor Positioning, and visually transformed using CSS Scroll State Queries (sticky menubar stuck-state and overflow shadows).

    • Layout Agnostic Subgrid Benefits

    By defining grid-template-columns: subgrid inside each .menu-item, the subgrid directs the sizing tracks back to the root .menu-list definitions. This means:

    • Icons: Always occupy identical width columns, even if one icon has a different aspect ratio.
    • Text: Takes up all remaining available horizontal space in column 2.
    • Shortcuts: Vertically line up beautifully to the right, regardless of varying text lengths.
    • Submenu Arrows: Line up perfectly right-aligned inside the same layout boundary.

    This completely removes the need for magic margin offsets or hardcoded column width variables across menu list items, making it fully fluid and reliable.
