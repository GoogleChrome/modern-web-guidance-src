- The breadcrumb trail is wrapped in a `<nav>` element with a non-empty `aria-label`.
- The `<nav>` contains an ordered list (`<ol>`) whose `<li>` items each contain an `<a>`.
- The last item's link has `aria-current="page"`, and no other trail link has it.
- Divider characters are not present as text in the DOM; they are generated via CSS `::before` content (or a mask) on `li + li`.
- The divider generated by CSS uses empty alt text (`/ ""`) or has no text content, so the accessible names of the list items contain no divider characters.
- Links in the trail show a visible focus indicator (non-zero outline or distinct style) when focused with the keyboard.
- Each sibling dropdown trigger is a `<button type="button">` with a `popovertarget` attribute and a non-empty `aria-label`, placed outside the ancestor's `<a>`.
- Each sibling dropdown trigger's target is an element with the `popover` attribute containing `<a>` links.
- Activating a sibling dropdown trigger opens its popover, and pressing Escape closes it.
- The ancestor link next to a sibling trigger remains a navigable `<a>` with an `href`.
- The `<nav>` (or an ancestor wrapper) has `container-type: inline-size`, and a container query hides middle trail items at narrow widths.
- In a trail with more than four items at a narrow container width, a "…" `<button>` with `popovertarget` and an `aria-label` is visible and hidden items are not displayed.
- Hidden middle items are not focusable at narrow container widths (`display: none`).
- Hovering a non-current trail link changes its computed color or background color.
- The current-page link has a computed color or font weight different from the other trail links.
- In a trail using shaped (arrow or slant) segments inside an `rtl` container, the segment polygon differs from the `ltr` one and is mirrored horizontally.
