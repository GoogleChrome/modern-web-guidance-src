Breadcrumb demos

A trail showing where you are in the site hierarchy, with links to each ancestor and, optionally, sibling pages in a dropdown. The current page is a link with aria-current="page". Tab through each to check focus styles. The last section has resizable containers.

9. Sibling dropdowns (popover)

Each ancestor can have a small button joined to its link that opens a list of sibling pages. The link still navigates to the ancestor. The current sibling is labeled “Current”.

10. Deep nesting, collapsed (container query)

Trails with more than four items get a “…” button (added by JS) that opens a popover listing the middle items. Below 40rem of container width the middle collapses; below 20rem the trail becomes a single “‹ Parent” link.
