Content-Aware Card Component

This demo illustrates a semantic card component. By querying its parent layout wrapper container using Container Queries and modern :has() selectors, the card automatically reconfigures its layout structure dynamically.

Example 1 — Card Layout in Narrow Viewport (Static Mobile Preview)

A static mobile preview of the card with an image. Because the container is narrow (under 320px), the card naturally stacks elements vertically in their exact HTML source order.
