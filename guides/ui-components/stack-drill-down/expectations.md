- The stack container enables mandatory horizontal scroll snapping (`scroll-snap-type: x mandatory` or `inline mandatory`).
- The stack container scrolls horizontally via `overflow-x: auto` or `overflow-x: scroll`.
- Each view has a width equal to the stack container width and is not absolutely positioned.
- The stack container sets `overscroll-behavior-x: none` to suppress browser back/forward swipe navigation.
- The stack container spans the full viewport height using `100dvh`.
- Each view sets `scroll-snap-align: start`.
- Each view sets `scroll-snap-stop: always`.
- The stack container hides its visible horizontal scrollbar.
- Each view nests an inner content element that handles vertical scrolling, an opaque background, and parallax transforms instead of applying transforms directly to the outer snap target.
- Scroll-driven parallax animation rules are wrapped in `@supports (animation-timeline: view())`.
- The parallax animation uses `animation-timeline: view(inline)` with `animation-range` confined to the `exit` phase.
- Drill-down views render a leading-edge `box-shadow`, while the root view does not.
- Smooth scrolling (`scroll-behavior: smooth`) on the stack container is declared only inside `@media (prefers-reduced-motion: no-preference)`.
- Programmatic scrolls on the stack container use `behavior: 'auto'` or `'instant'`, never hardcoded `'smooth'`.
- Active-view-change detection listens for the `scrollsnapchange` event on the stack container.
- When `scrollsnapchange` is unsupported, active-view-change detection falls back to an `IntersectionObserver` rooted at the stack container with `threshold: 1`.
- Every view in the stack except the currently active view carries the `inert` attribute.
- Views that are swiped or navigated back past are removed from the DOM.
- When a new drill-down view becomes active, keyboard focus moves to its back button.
- When returning to a previous view, keyboard focus is restored to the link that triggered the drill-down.
- Programmatic `focus()` calls inside the stack pass `{ preventScroll: true }`.
- Drill-down triggers are anchor elements (`<a>`) with `href` attributes.
- The click handler ignores clicks with modifier keys (`metaKey`, `ctrlKey`, `shiftKey`, `altKey`) or non-primary mouse buttons.
- Clicks on external or unhandled links are not intercepted with `preventDefault()`.
- Drill-down views include an explicit back button, while the root view does not.
- Drilling down pushes a new entry via `history.pushState()` with depth tracking.
- A `popstate` listener on `window` scrolls the stack to match browser back/forward navigation.
- Swiping back manually reconciles browser history via `history.go()` when the active view depth changes.
- Loading a deep-linked URL opens the corresponding drill-down view and allows navigating back to the root view.
