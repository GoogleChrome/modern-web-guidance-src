- The document `<head>` includes the `<meta name="text-scale" content="scale">` element to opt into operating system text scaling.
- Font sizes use relative units (`rem` or `em`) rather than fixed pixels (`px`) or bare viewport units (`vw`) alone, line heights use unitless values, and spacing (margins and padding) coupled to text size uses relative units.
- Text resizes to at least 200% of its default size without loss of content or functionality, and responsive layouts reflow at a 320 CSS-pixel viewport width without two-dimensional scrolling.
- Text-containing components and containers grow to accommodate scaled text without fixed `height` or `block-size` values or restrictive `max-height` or `max-block-size` values that cause clipping or overflow.
- Text within scaled containers wraps naturally without restrictive inline-axis clipping, fixed widths, or `white-space: nowrap` on text blocks.
- When the `<meta name="text-scale" content="scale">` element is present, the CSS stylesheet does not explicitly set `font-size` on `:root` or `html` (including absolute, relative, or calculated values).
