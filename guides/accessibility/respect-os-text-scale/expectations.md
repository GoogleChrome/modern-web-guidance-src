- The implementation MUST opt into operating system text scaling using the `<meta name="text-scale" content="scale">` element in the document `<head>`.
- **MANDATORY**: Font sizes MUST include relative units (`rem` or `em`) rather than relying exclusively on viewport units such as `vw`, and margins and padding MUST use relative units so they respond to the scaled root font size. Line heights MUST be unitless so they scale proportionally with each element’s computed font size.
- **MANDATORY**: Sizing on text-containing components and containers MUST avoid fixed heights (`height`) or restricted vertical dimensions, utilizing flexible heights (such as `min-height` or `auto`) to prevent text clipping and container overflow when text is scaled.
- **MANDATORY**: Text within scaled containers MUST be allowed to wrap naturally (avoiding restrictive inline-axis clipping, fixed widths, or `nowrap` on text blocks) to ensure content remains readable when enlarged.
- **MANDATORY**: When the `<meta name="text-scale" content="scale">` element is present, the CSS stylesheet MUST NOT explicitly set `font-size` on either `:root` or `html`, including values expressed in absolute units, relative units, or calculated values, so the browser can apply operating system text scaling without being overridden or applied twice.
- **MANDATORY WHEN FALLBACKS ARE RELEVANT**: On browsers where the `<meta name="text-scale">` tag is not supported, the page MUST degrade gracefully by displaying the layout at the browser's default standard base font size.
