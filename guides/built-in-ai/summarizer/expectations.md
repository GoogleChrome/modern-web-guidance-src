- The `Summarizer` API should be available in the browser on `window.Summarizer`, but not on `window.ai.summarizer`.
- The `Summarizer.availability()` function should return `available` or `downloadable` or `downloading` or `unavailable`.
- The same options should be passed to both `Summarizer.availability()` and `Summarizer.create()`.
