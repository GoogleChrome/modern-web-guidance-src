- Deep cloning of structured in-memory state (objects, arrays, `Date`, `Map`, `Set`, and typed arrays) uses `structuredClone()` rather than `JSON.parse(JSON.stringify(...))` when JSON wire normalization is not required.
- Non-mutating array sorting uses `Array.prototype.toSorted()` instead of cloning and mutating with `[...arr].sort()`, `arr.slice().sort()`, or `Array.from(arr).sort()`.
- Non-mutating array reversal uses `Array.prototype.toReversed()` instead of cloning and mutating with `[...arr].reverse()` or `arr.slice().reverse()`.
- Non-mutating array element removal, insertion, and single-index replacement use `Array.prototype.toSpliced()` and `Array.prototype.with()` instead of shallow-copying the array before mutating it in place.
- Searching an array from the end uses `Array.prototype.findLast()` or `Array.prototype.findLastIndex()` instead of reversing a copy of the array before calling `.find()`.
- Partitioning an iterable into array buckets by key uses `Object.groupBy()` (for string or symbol keys) or `Map.groupBy()` (for non-string or object keys) instead of `.reduce()` bucket accumulator loops.
- Key existence checks on the `null`-prototype object returned by `Object.groupBy()` use `Object.hasOwn(groups, key)` or nullish coalescing (`groups[key] ?? []`) rather than `groups.hasOwnProperty(key)`.
- Deferred promise construction where `resolve` or `reject` is invoked outside the executor callback uses `Promise.withResolvers()` instead of assigning to mutable outer `let resolve, reject` bindings.
- Time-bounded asynchronous operations use `AbortSignal.timeout(ms)` (and combine user-controlled `AbortController` signals with deadlines via `AbortSignal.any([...])`) instead of manual `setTimeout(() => controller.abort(), ms)` timers.
- Timeout error handling for `AbortSignal.timeout()` checks for `DOMException` instances with `error.name === 'TimeoutError'` in addition to user-initiated `'AbortError'`.
- Catch blocks that wrap and re-throw an error attach the caught error via the options parameter `new Error(message, { cause: err })` rather than concatenating `err.message` or discarding the original error instance.
- URL query-string parsing and serialization use `URLSearchParams` (or `new URL(url, base).searchParams`) and `Object.fromEntries()` instead of manual `.split('&')` and `.split('=')` string splitting with `decodeURIComponent()`.
- Decoding UTF-8 `Uint8Array` byte buffers into strings uses `TextDecoder` (passing `{ stream: true }` for chunked byte streams) instead of `String.fromCharCode.apply(null, bytes)` or `String.fromCharCode(...bytes)`.
- Clearing all children of a DOM element or replacing them with new nodes uses `element.replaceChildren()` (or `template.content.replaceChildren()` for `<template>` elements) instead of `element.innerHTML = ''` or `while (element.firstChild) element.removeChild(element.firstChild)` loops.
- Constructing synthetic DOM events uses `new Event(type, options)` and `new CustomEvent(type, { detail, ...options })` instead of `document.createEvent()` and `initEvent()` or `initCustomEvent()`.
