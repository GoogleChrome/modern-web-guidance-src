Load a popular web font via Cross-Origin Storage

This page requests a large, popular emoji font that many unrelated sites already share in Cross-Origin Storage. The src list above resolves to the same font either way -- via COS in a browser that has already cached it, or over the network otherwise. The plain url() fallback is what makes this safe to ship today, in every browser, without waiting for COS support.
