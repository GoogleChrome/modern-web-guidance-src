Modal Dialog Scroll Containment Demo

Open a modal dialog below and try scrolling both inside the dialog and over the backdrop. The page underneath will not scroll.

Short Dialog

This modal dialog does not overflow, yet overscroll-behavior: contain still prevents scroll events inside the dialog or on its backdrop from scrolling the page underneath.
