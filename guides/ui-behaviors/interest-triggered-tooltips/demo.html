The document Document Object Model — the browser's in-memory representation of a web page's structure. is a tree structure that represents the content of a web page. Each node in the tree corresponds to an element, and nodes can have Key-value pairs on HTML elements that configure behavior or provide metadata, such as class or id. that provide additional information about the element.
