Spatial Focus Navigation

This demo implements visual 2D directional navigation using a bounding-rect distance heuristic and roving tabindex focus management.

Interactive Instructions: Press Tab to focus on the first card, then use the Arrow Keys to navigate spatially across rows and columns.
Pressing arrows at boundaries (e.g. Down at the bottom cards or Up at the top cards) allows the browser to scroll the viewport natively.
