Sortable table

Requirements: a plain, semantic <table> whose column headers become buttons that sort the rows. The current sort is exposed with aria-sort on the <th>, one polite role="status" message is announced per sort, and focus stays on the header button.

Platform features: Invoker Commands (commandfor + custom --sort commands, handled by one command listener on the table), element-scoped View Transitions with view-transition-name: match-element for row animation, and moveBefore() to reorder the existing <tr> nodes (falling back to append()). The table scrolls horizontally in a wrapper on narrow screens, and the animation is disabled under prefers-reduced-motion.
