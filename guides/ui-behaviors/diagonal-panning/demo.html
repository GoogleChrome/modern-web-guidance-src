Diagonal Panning with CSS scroll-axis-lock: none

Pan or scroll the 2D surface below using a trackpad or touchscreen (for example, in a diagonal or circular motion). With scroll-axis-lock: none enabled, the scroll container immediately follows both horizontal and vertical deltas without locking to a single axis.

Note: Your browser does not natively support scroll-axis-lock: none. When none is selected below, this demo activates the JavaScript fallback (applying raw wheel and pointermove deltas to scrollLeft and scrollTop).
