Draggable Overlay Dialog Component

This demo illustrates a fully draggable modal overlay using standard pointer events. The header behaves as the drag handle utilizing user-select: none to prevent mouse-drag highlight artifacts, while keeping the contents inside the body completely selectable.

Example — Desktop & Mobile Draggable Modal

Draggable Dialog

Click and drag the header title bar above to move this modal around freely inside the boundary limits.

Selectable: You can still drag-select, highlight, and copy this specific segment of text freely.

HTML Structure

<div class="dialog" id="dragDialog">
  <div class="dialog-header" id="dialogHeader">
    <span class="dialog-title">Draggable Dialog</span>
    <button class="btn-close" id="closeBtn">✕</button>
  </div>
  <div class="dialog-body">
    <p>Content here...</p>
  </div>
</div>

CSS Style Rules

/* Style drag handle strictly */
.dialog-header {
  cursor: grab;
  /* REQUIRED: Prevents highlighting text inside the header bar when clicking and dragging */
  user-select: none;
  -webkit-user-select: none;
  -ms-user-select: none;
}
.dialog-header.dragging {
  cursor: grabbing;
}
/* Ensure the dialog fits on touch screens without scrolling parent contents */
.dialog {
  position: absolute;
  touch-action: none; /* stop browser scrolling gestures */
}
