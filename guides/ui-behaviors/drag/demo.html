Draggable Native Dialog Component

This demo illustrates a single draggable native <dialog>. Toggle between Modal and Non-Modal modes. Keyboard-friendly nudge commands (focused on the header) let keyboard users relocate the dialog, while non-modal Esc key closing ensures complete accessibility compliance.

Example — Desktop & Mobile Draggable <dialog>

Draggable Dialog

Drag my header title bar above, or focus it and use the keyboard arrow keys to reposition this dialog panel.

Selectable: Body text remains copyable and selectable.
View Source Code

HTML Structure

<!-- Native dialog element -->
<dialog class="dialog" id="dragDialog">
  <!-- tabindex="0" makes the header keyboard focusable -->
  <div class="dialog-header" id="dialogHeader" tabindex="0" role="application" aria-label="Dialog header. Use arrow keys to reposition.">
    <span class="dialog-title">Draggable Dialog</span>
    <button class="btn-close" id="closeBtn">✕</button>
  </div>
  <div class="dialog-body">
    <p>Body content...</p>
  </div>
</dialog>

CSS Style Rules

dialog.dialog {
  position: fixed;
  /* REQUIRED: overrides the browser default 'margin: auto' so coordinate left/top are respected */
  margin: 0;
  touch-action: none; /* Stops browser scrolling gestures */
  z-index: 1000; /* Ensure visibility over background text in modeless mode */
}

/* Style drag handle strictly */
.dialog-header {
  cursor: grab;
  /* REQUIRED: Prevents highlighting text inside the header bar when clicking and dragging */
  user-select: none;
  -webkit-user-select: none;
}
.dialog-header.dragging {
  cursor: grabbing;
}
.dialog-header:focus-visible {
  outline: 2px solid var(--focus-ring-color);
  outline-offset: -4px;
}
