- Buttons use the "commandfor" and "command" attributes to trigger actions.
- All custom command names start with "--".
- Invoker buttons have initial accessibility attributes (e.g., `aria-pressed="false"`) where appropriate.
- Clicking the "Spin" button toggles the "is-spun" class on the target element.
- Clicking the "Grow" button toggles the "is-grown" class on the target element.
- Clicking the "Make Round" button toggles the "is-rounded" class on the target element.
- Clicking the "Reset All" button removes the "is-spun", "is-grown", and "is-rounded" classes from the target element.
- When a toggle action is triggered, the `aria-pressed` attribute of the source button (`event.source`) is updated to reflect the new state.
- The `command` event listener is attached directly to the target element and reads `event.command` and `event.source`.
- The implementation checks for native support of the Invoker Commands API (e.g., `'commandForElement' in HTMLButtonElement.prototype` or `globalThis.CommandEvent`) before conditionally loading the `invokers-polyfill` fallback.
