- The application checks for modern WebCrypto algorithm support using the static `SubtleCrypto.supports()` method and falls back to classical WebCrypto (`X25519` or `ECDH` with `HKDF` and `AES-GCM`) when unsupported.
- When modern WebCrypto algorithms are supported, the application generates a KEM key pair with `['encapsulateKey', 'decapsulateKey']` usages and establishes a shared encryption key using `crypto.subtle.encapsulateKey()` and `crypto.subtle.decapsulateKey()` with `'MLKEM768-X25519'`, `'ML-KEM-768'`, or `'ML-KEM-1024'`.
- The application exports or imports the recipient public key (or key material) using the explicit modern WebCrypto raw key formats (`'raw-public'`, `'raw-seed'`, or `'raw-secret'`, falling back to `'raw'` for classical keys) rather than passing the legacy `'raw'` format to modern WebCrypto algorithms.
- The application encrypts plaintext data using an authenticated encryption algorithm (`'ChaCha20-Poly1305'` or `'AES-GCM'`) with a freshly generated 12-byte (96-bit) initialization vector (`iv`) from `crypto.getRandomValues()`.
- Decapsulating the key capsule and decrypting the ciphertext with `crypto.subtle.decrypt()` recovers the original plaintext in the UI.
