Local Network & Loopback Access

Connect to devices on the local network (local-network) and companion apps on 127.0.0.1 / localhost (loopback-network) with explicit targetAddressSpace declarations and permission state handling. (Note: Because localhost is already in the loopback address space, to test permission denial locally toggle Local network / Loopback network in Chrome Site settings or launch Chrome with --ip-address-space-overrides=127.0.0.1:PORT=public.)
